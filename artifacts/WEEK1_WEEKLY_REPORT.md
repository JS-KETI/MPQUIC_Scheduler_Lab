## 3. 막힌 점과 원인 확인 · 단일 경로 시간 기준 초과

![최초 실패와 조건별 검증·원본 조건 재검증 비교](report-visuals-2026-10-01/one_path_comparison.png)

- **최초 문제 상황(현상)**
  - 고정 5Mbps에서 3회 모두 전체 바이트 수신, 전송 시간은 9.4560초로 기준 상한 9.0초 초과
- **문제 정의·식별**
  - 최초 링크 속도는 고정 5Mbps, 원본 실행 스크립트는 5~6Mbps로 조건 불일치
  - 속도만 원본 범위로 바꾼 통제 실험에서 시간 기준 충족 → 속도 설정 차이가 주요 원인
- **접근(수정) 방법**
  - 원본 조건인 속도 5~6Mbps·지연 50~55ms·RR로 정렬. 목표 5,242,880B·손실률 0·OLIA 유지
  - 수신 시각·링크 조건을 기록하는 기본 비활성 관찰 옵션 추가
- **결과**
  - seed 1~10 모두 목표 바이트 전체 수신·시간 기준 충족. 관찰 전후 IP 추적 일치
  - 원본 조건에 맞춘 재현 결과이며, 고정 5Mbps 성능 개선으로 해석하지 않음. 최초 실패 기록 보존

**남은 확인:** 목표 바이트 미달 29건은 제공 기준 CSV에도 존재. 완료 처리와 전체 수신을 구분하고, 종료 조건·전송 정체의 영향을 추가 분석할 필요가 있음.
