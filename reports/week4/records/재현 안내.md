# 4주차 재현 패키지

## 환경 준비

- 검증 환경: Ubuntu24.04·WSL2, g++13, Python3.12.
- 분석 버전: numpy1.26.4, pandas2.1.4, scipy1.11.4, matplotlib3.6.3.
- 패키지는 원본01+02, 승인된2주차 공통 수정,3주차 슬롯·계측,4주차 실험 설정이 적용된 소스. 패치를 다시 적용하지 않음.
- SOURCE_VERSION.json의 commit·source SHA256과 patches/의 변경 이력으로 버전 확인.

```bash
sudo apt-get update
sudo apt-get install -y build-essential python3 git libeigen3-dev python3-numpy python3-pandas python3-scipy python3-matplotlib
tar -xzf week4-reproduction.tar.gz
cd week4-reproduction
sha256sum -c SHA256SUMS
bash sched-lab/setup-week4.sh
```

## 기존 측정값으로 표·그림 재생성

```bash
python3 sched-lab/week4_analyze.py \
  --runs artifacts/week4/runs/2026-10-18/run-03 \
         artifacts/week4/runs/2026-10-18/run-04 \
         artifacts/week4/runs/2026-10-18/run-05 \
         artifacts/week4/runs/2026-10-18/run-06 \
  --out reproduced-analysis
```

- reproduced-analysis/summary.csv: 전체 실행 수·완료·전체수신·평균/중앙값/p90·95% 신뢰구간.
- paired_comparisons.csv: 같은seed에서 두스케줄러가 모두 완료한 시간차·95%CI·Wilcoxon·승패.
- baseline-long_fct.png: 제공 analyze.py의 기본 전송시간 상자그림. 완료/전체 실행 수 표시.
- figures/: 완료·전체수신율, 경로1 IP 바이트 비중, 열화·강건성 결과표,4경로 사용범위.
- 폴더가 이미 있으면 새 출력 이름 사용. 동결 원시데이터/분석은 덮어쓰지 않음.

## 새 측정 재현

```bash
python3 sched-lab/week4_run.py --group short --out artifacts/week4/runs/reproduction/run-01 --jobs 4
python3 sched-lab/week4_run.py --group long --out artifacts/week4/runs/reproduction/run-02 --jobs 4
python3 sched-lab/week4_run.py --group robustness --out artifacts/week4/runs/reproduction/run-03 --jobs 4
python3 sched-lab/week4_run.py --group four_path --out artifacts/week4/runs/reproduction/run-04 --jobs 2
python3 sched-lab/week4_analyze.py --runs artifacts/week4/runs/reproduction/run-01 artifacts/week4/runs/reproduction/run-02 artifacts/week4/runs/reproduction/run-03 artifacts/week4/runs/reproduction/run-04 --out reproduced-new-analysis
```

- 원본 조건회귀105·열화변형210·장시간210·강건성630·4경로8회=1,163회. 실제 명령은 시행별 command.json에 보존.
- 장시간은50MiB·QUIC 버퍼4종 각각80,000,000B·종료180초. 나머지5MiB·40,000,000B·60초가 기본이며 버퍼변형만 별도.
- 모든 비교는OLIA·완료목표−3000B·종료대기250ms 고정. 손실률 실험은forward 병목 패킷단위0.1/1%.
- 제한시간 내 미완료는 실행 자체의 오류가 아님. process status,done,rx_app를 각각 확인.
- FCT95는목표95%바이트 도달시간. 미완료여도95%도달한 실행을 포함. p90 FCT와별도.
-4경로는기존스케줄러의경로사용한계확인.전체스케줄러의N경로최적화나자동분배알고리즘은포함하지않음.

## 보존 데이터와 확인 범위

-2주차baseline.csv는5MiB 기준값. 새로운baseline-long.csv와혼합하지않음.
-첫 장시간40MB버퍼 예비실패와80MB비교,작은큐·버퍼·손실에따른미완료도원본run에보존.
-SHA256SUMS·SOURCE_VERSION.json·실제재현검증기록으로패키지내용과소스구성확인.
-예비실행명령은 --group pilot 또는 --group buffer_pilot. 전체재측정과예비재현의검증범위를구분.
