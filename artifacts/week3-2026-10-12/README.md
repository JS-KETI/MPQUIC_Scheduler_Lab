## 3주차 실행 기록

- run-01: 최초 고정 진단, 72회 전체 수신, 25/27 비율 오차 초과. 원시 로그·소스 보존
- run-02: 양 경로 배치 대기·초기 창 성장, 분배27/27 충족, degrade50/50의 3회 미완료. 당시 protocol 정정은 PROTOCOL_AMENDMENT.json
- run-03: 창 축소 회복 예외 포함, 72회 전체 수신·45/45 기준 대조·27/27 비율 충족. 최종 검증 데이터
- 모든 source/는 해당 측정 당시 소스, final-source/는 최종 게시 코드. 2주차 공식 동결 데이터를 변경하지 않음
- trace-equivalence는 새 계측 on/off 7쌍·14회 추가 관찰 대조. 기본 72행에 합치지 않음
- 신규 고정 비율은 제공 기준 없음. 기존 ID와 초기 ID7의 대조는 공식 2주차 같은 seed 사용
- 동결 기준과 신규 고정 진단을 혼합해 성능 평균을 만들지 않음
