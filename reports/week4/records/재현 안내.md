# 4주차 재현 패키지

## 환경 준비

- 검증 환경: Ubuntu 24.04·WSL2, g++ 13, Python 3.12
- 분석 라이브러리: numpy 1.26.4, pandas 2.1.4, scipy 1.11.4, matplotlib 3.6.3
- 제공 01+02, 승인된 2주차 공통 수정, 3주차 슬롯·계측, 4주차 설정이 이미 적용된 소스. 동봉 패치는 이력 확인용이며 다시 적용하지 않음
- SOURCE_VERSION.json의 소스 커밋·파일 해시와 SHA256SUMS로 실제 파일 구성 확인

```bash
sudo apt-get update
sudo apt-get install -y build-essential python3 python3-dev git libeigen3-dev python3-numpy python3-pandas python3-scipy python3-matplotlib xz-utils
tar -xJf week4-reproduction.tar.xz
cd week4-reproduction
sha256sum -c SHA256SUMS
bash sched-lab/setup-week4.sh
python3 sched-lab/test_week4_analysis.py -q
```

## 동봉 측정값으로 표·그림 재생성

```bash
python3 sched-lab/week4_analyze.py   --runs artifacts/week4/runs/2026-10-18/run-03          artifacts/week4/runs/2026-10-18/run-04          artifacts/week4/runs/2026-10-18/run-05          artifacts/week4/runs/2026-10-18/run-06   --out reproduced-analysis
python3 sched-lab/plot_week4_overview.py reproduced-analysis/summary.csv reproduced-analysis/robustness_overview.png
```

- summary.csv: 전체 실행 수·완료·전체 수신·평균·중앙값·p90·평균의 95% 신뢰구간
- paired_comparisons.csv: 같은 seed에서 두 스케줄러가 모두 완료한 시간 차이·신뢰구간·Wilcoxon·승패
- observed_rank_changes.csv: 설정 전후 두 스케줄러 모두 완료한 같은 seed로 비교한 시간 우열 변화
- baseline-long_fct.png: 제공 analyze.py의 전송 시간 상자그림. 완료/전체 실행 수 표시
- figures/: 완료·전체 수신율, 경로 1 IP 비중, 열화·강건성, 4경로 사용 범위
- FCT95는 목표 95% 바이트 도달 시간. 미완료라도 95%에 도달하면 평균에 포함. p90 FCT와 다른 지표
- 출력 폴더가 이미 있으면 새 이름 사용. 동결한 원본은 덮어쓰지 않음

## 새 측정 재현

```bash
python3 sched-lab/week4_run.py --group short --out artifacts/week4/runs/reproduction/run-01 --jobs 4
python3 sched-lab/week4_run.py --group long --out artifacts/week4/runs/reproduction/run-02 --jobs 4
python3 sched-lab/week4_run.py --group robustness --out artifacts/week4/runs/reproduction/run-03 --jobs 4
python3 sched-lab/week4_run.py --group four_path --out artifacts/week4/runs/reproduction/run-04 --jobs 2
python3 sched-lab/week4_analyze.py --runs artifacts/week4/runs/reproduction/run-01 artifacts/week4/runs/reproduction/run-02 artifacts/week4/runs/reproduction/run-03 artifacts/week4/runs/reproduction/run-04 --out reproduced-new-analysis
```

- 본 측정은 기존 조건 105·열화 210·장시간 210·강건성 630·4경로 8회, 합계 1,163회
- 장시간은 50MiB·버퍼 4종 각각 80,000,000B·종료 시각 180초. 나머지는 5MiB·40,000,000B·60초 기본, 버퍼 변화 실험은 명시값 적용
- OLIA·완료 목표−3,000B·종료 대기 250ms 유지. 손실률 실험은 forward 병목의 패킷 단위 0.1%·1%
- 제한 시각 내 미완료는 정상 실행 결과일 수 있음. process status·done·rx_app를 분리해 확인
- 예비 명령은 --group pilot / --group buffer_pilot. 최초 40MB 정체·80MB 변경·작은 큐와 버퍼 결과도 동봉

## 검증 기록과 적용 범위

- records/reproduction-validation.json: 새 소스 빌드·단위 검증, 13회×21개 필드 재현, 전체 데이터 재분석 CSV 9개·그림 6개 및 요약 그림 일치
- 전체 1,163회 시뮬레이션을 재실행한 검증과 구분. 재현한 13회 원본은 records/reproduction-runs/에 보존
- 2주차 baseline.csv는 기존 5MiB 기준. 장시간 baseline-long.csv는 미완료 4회를 포함한 별도 기준
- 4경로는 기존 스케줄러의 동작 범위 확인. 자동 분배 알고리즘과 모든 스케줄러의 N경로 재작성은 포함하지 않음
- SOURCE_VERSION.json은 Git이 없는 압축 해제 환경의 소스 버전·해시 근거. README는 패키지 사용 안내로 대체된 파일
