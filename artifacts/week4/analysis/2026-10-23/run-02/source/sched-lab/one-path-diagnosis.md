### 시도 7 — 원본 조건과 정확 목표 바이트

- 추정 원인: 전체 수신 대신 95%나 Size-3000B를 완료로 판정하면 이전 결과가 기준을 충족했을 가능성.

- 성공 여부: 관찰 성공 / 완료 기준을 낮춰도 고정 5Mbps 시간 미달 설명에 부족 / 전체 바이트 기준 유지.
- 단순 페이로드 전송 하한 5,242,880×8/5,000,000 = 8.388608초. 측정과의 나머지는 헤더·연결·혼잡 제어·ACK 대기 등을 포함하며 이 분석에서는 개별 비중을 확정하지 않음.
