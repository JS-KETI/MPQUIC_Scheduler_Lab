# 2주차 제공 기준 대조 기록

- 비교 기준: 제공 results_fixed_stack.csv, 01+02 패치 적용. 원 스택(01만 적용)의 별도 CSV는 이번 실험과 조건이 달라 비교하지 않음
- 제공 범위: seed 1~10, 3시나리오 × 7스케줄러 × 10회 = 210회
- 제공 기준과 이번 실행 모두 완료 처리 191/210, 목표 바이트 전체 수신 181/210
- 제공 기준의 미달 29건 = 완료 처리 후 바이트 부족 10건 + 완료 기준 미충족 19건
- 동일 조합·seed의 9개 측정 항목 1,890개 셀 모두 일치. 비교 가능한 범위에서 이번 실행에만 발생한 미달 0건
- 추가 seed 11~30: 420회 중 완료 처리 377회·전체 수신 352회. 미달 68건 = 완료 처리 후 바이트 부족 25건 + 미완료 43건
- 추가 seed의 제공 기준은 없음. 68건은 확대 측정에서 확인한 결과이며, 우리 환경에만 발생했는지 판정 불가
- 전체 630회 수치 568/630·533/630은 위 두 범위의 합계
- 원시 run-01은 동결 상태 그대로 보존. 이번 대조 CSV·검증 기록을 별도 폴더에 추가

## 파일

- provided_results_fixed_stack.csv: 제공 기준의 바이트 동일 사본
- provided_seed1_10_comparison.csv: 같은 조합·seed별 제공값·측정값·일치 여부
- reference_scope_summary.csv: 제공 범위·추가 seed·전체의 완료 처리·수신량 집계
- seed11_30_below_target_without_reference.csv: 제공 기준이 없는 추가 seed의 미달 68건
- validation.json: 비교 파일 해시·항목·범위·차이 수
